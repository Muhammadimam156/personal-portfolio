# Public Assets Folder

## Profile Image Instructions

Your profile picture has been set up in the Hero component to load from `/profile.jpg`.

### To add your profile image:

1. **Save your image as `profile.jpg`** in this folder (`public/profile.jpg`)
   - Supported formats: JPG, PNG, WebP
   - Recommended size: 400x400px or larger (square aspect ratio)
   - File size: Keep under 500KB for optimal performance

2. **Image requirements:**
   - Square format (1:1 aspect ratio) works best
   - Minimum resolution: 400x400px
   - Professional headshot recommended

3. **After adding the image:**
   - Refresh your browser (the dev server will auto-detect the change)
   - Your profile picture will automatically appear in the hero section

### Example:
- Place your image at: `my portfolio/public/profile.jpg`

The image will be automatically optimized and displayed with a floating animation effect!
